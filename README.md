# 📅 BookIt — Система онлайн-записи

Веб-приложение для записи на услуги. Пользователи могут просматривать каталог услуг, записываться на удобное время, управлять своими записями. Администратор управляет услугами и видит все записи.

## 📊 Схема базы данных

Три таблицы со связями:

```mermaid
erDiagram
    users ||--o{ bookings : "1:N (user_id)"
    services ||--o{ bookings : "1:N (service_id)"

    users {
        int id PK
        text username
        text password_hash
        text role
    }
    services {
        int id PK
        text name
        text description
        real price
        int duration
        int active
    }
    bookings {
        int id PK
        int user_id FK
        int service_id FK
        text booking_date
        text booking_time
        text status
    }


- `users.id` → `bookings.user_id` (один пользователь — много записей)
- `services.id` → `bookings.service_id` (одна услуга — много записей)

## ✅ Реализованный функционал

### 👤 Пользователи
- Регистрация нового аккаунта (валидация логина и пароля)
- Вход / выход из системы (JWT в HttpOnly cookie)
- Отображение имени и роли в шапке
- Защита от дубликатов при регистрации

### 💈 Услуги
- Каталог услуг в виде карточек с названием, описанием, ценой и длительностью
- 🔍 Поиск по названию с debounce (300мс)
- 📊 Сортировка по цене (↑↓), длительности, названию
- Кнопка «Записаться» на каждой карточке

### 📅 Запись
- Выбор услуги → даты → времени через визуальные слоты
- 🕐 Занятые слоты отображаются перечёркнутыми (загружаются с API)
- ⏰ Прошедшие слоты автоматически блокируются
- Итоговая стоимость и длительность перед подтверждением
- Просмотр своих записей со статусами (активна / отменена)
- Отмена записи через модальное окно подтверждения
- ✅ Toast-уведомления при успешных действиях

### 🛡 Защита и проверки
- Нельзя записаться без авторизации
- Нельзя записаться на прошедшую дату или время
- Нельзя записаться на занятое время (проверка конфликтов)
- Нельзя записаться, если уже есть запись на это же время
- Нельзя отменить чужую запись (проверка user_id)
- Логирование действий пользователей в консоли сервера
- Попытка отмены чужой записи логируется как `[SECURITY]`

### 👑 Администратор
- Добавление новых услуг (название, описание, цена, длительность)
- Удаление услуг (soft delete — деактивация)
- Просмотр всех записей всех пользователей
- 📈 Статистика: всего / активных / отменённых записей
